# 오프라인 데스크톱 펫

## 사용하기 (Windows 11)

알림 영역의 시사 아이콘을 우클릭하고 **데스크톱 펫**을 엽니다. 시사·하치와레·랏코·모몽가·우사기를 각각 소환하거나 **친구들 함께 소환**으로 다섯 친구를 한꺼번에 부릅니다. 같은 캐릭터도 여러 번 소환할 수 있고 최대 12마리까지 표시합니다.

각 친구는 독립적인 위치·속도·방향·휴식 시간을 가지고 작업 표시줄을 제외한 화면 안을 돌아다닙니다. 마우스를 올리면 잠시 멈춥니다. 우클릭으로 그 친구를 돌려보내거나 전체 이동을 멈출 수 있습니다. 트레이 메뉴에서도 전체 휴식·이동·돌려보내기가 가능합니다. 소환 목록은 기존 앱의 로컬 `state.json`에 저장되며 다음 실행 때 복원됩니다. 위치와 휴식 상태는 실행할 때 새로 정합니다.

펫은 기존 비서 캐릭터에 추가되는 별도 기능입니다. 기존 캐릭터 클릭, 채팅, 대시보드, 집중 타이머는 그대로 사용합니다. 펫의 이미지와 움직임에는 AI 키·인터넷·데몬이 필요하지 않습니다. 앱의 기존 연결 기능과 업데이트 확인 설정은 별도로 유지됩니다. 새로운 그림을 다운로드하지 않고 저장소와 Windows 배포본에 포함된 캐릭터 에셋을 사용합니다.

## 기존 Electron 구조와 확장

- `desktop/main.js`: 단일 인스턴스, 창·트레이·IPC, 로컬 에셋 프로토콜, 데몬 실행과 SSE 전달을 담당합니다.
- `desktop/preload.cjs`와 `desktop/renderer/`: 격리된 렌더러에 기존 비서 기능을 제공합니다.
- `desktop/src/character.js`: 기본 다섯 캐릭터와 로컬 이미지 주소·대체 이미지 순서를 정의합니다.
- `agent/`: AI·할 일·연결 서비스 데몬입니다. 펫 이동은 이 계층을 호출하지 않습니다.
- `windows/dist-win.mjs`: 같은 Electron 앱과 로컬 에셋을 Windows 배포본에 넣습니다.

새 `src/pet-windows.js`는 캐릭터마다 포커스를 빼앗지 않는 투명 BrowserWindow를 만들고 하나의 30Hz 타이머로 각자의 이동 상태를 갱신합니다. `src/pet-motion.js`는 Electron 의존성이 없는 이동 계산입니다. 화면 작업 영역의 DIP 좌표를 사용하고, 화면 분리·해상도 변경 뒤에는 현재 디스플레이 작업 영역 안으로 위치를 보정합니다. 절전 복귀 시 이동 시간은 100ms로 제한합니다.

펫 렌더러는 preload나 IPC 권한 없이 로컬 이미지에만 접근합니다. 외부 탐색·새 창·네트워크 요청을 차단합니다. 마우스가 이미지 영역 밖에 있으면 클릭을 통과시키며, 이미지의 투명 픽셀 단위가 아니라 104px 사각형으로 호버를 판정합니다. 개별 이미지의 누락은 기존 대체 이미지로 처리합니다. 종료 시 모든 펫 창과 이동 타이머를 정리하되 소환 목록은 보존합니다.

## 검증

`cd desktop && npm test`로 기존 회귀 테스트 및 `test/pets.test.js`를 실행합니다. 신규 테스트는 독립 이동, 경계 반사, 음수 모니터 좌표, 작은 작업 영역, 절전 복귀, 소환 상한, 중복 캐릭터, 잘못된 저장 데이터, 복원 및 종료 시 목록 보존을 검증합니다.

Windows 11 실제 확인: 다섯 친구 동시 소환 → 같은 캐릭터 추가 → 각각 다른 경로로 이동 확인 → 호버 정지·우클릭 제거 → 전체 휴식·재개 → 재시작 복원 → 배율이 다른 모니터와 모니터 분리 → 네트워크 및 데몬을 끈 상태에서 소환·이동 확인. macOS 개발 환경의 자동 테스트만으로 Windows 합성기·DPI·알림 영역의 실제 동작까지 확인할 수는 없습니다.
