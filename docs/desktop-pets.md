# Windows 11 오프라인 데스크톱 친구들

## 사용하기

Portable ZIP 전체를 풀고 `Desktop Pets.cmd`를 실행하면 계정 로그인·관리자 권한·AI 모델 없이 펫 전용 모드로 시작합니다. Electron 런타임, 기존 캐릭터 그림·영상과 비서 코드가 포함됩니다. 인터넷이 되는 Windows 빌드 환경에서 한 번 패키징한 ZIP을 폐쇄망으로 반입합니다. 실행 PC에 Node.js나 npm을 설치할 필요는 없습니다.

트레이의 **데스크톱 펫 → 친구 소환·설정**에서 여러 종류를 선택하고 각각의 소환 개수를 정합니다. 같은 캐릭터도 중복 소환할 수 있고 최대 24마리까지 표시합니다. 기본 제공 리소스는 원본의 시사·하치와레·우사기·모몽가·랏코입니다. 치이카와·쿠리만쥬는 확장 항목으로 제공하며, 그림을 추가하기 전에는 이름표를 표시합니다. 원본 비서의 사용자 캐릭터도 로컬 저장 폴더에서 읽어 목록에 추가합니다.

각 친구의 크기(64~256 DIP), 속도(0.25~3배), 행동 빈도(0.25~3배), 성격과 표시 모니터를 변경할 수 있습니다. 전체 일시정지·상호작용·항상 위 표시를 켜고 끌 수 있습니다. 왼쪽 버튼으로 드래그하면 이동이 멈추고, 놓은 뒤 마우스를 다른 곳으로 옮기면 자율 행동이 재개됩니다. 우클릭 메뉴에서 그 친구의 설정을 열거나 돌려보낼 수 있습니다. 투명 여백의 클릭은 통과시키지만 이미지 내부의 투명 픽셀까지 판별하지는 않습니다.

목록·위치·크기·속도·행동 빈도·모니터·성격·전역 설정은 기존 `state.json`의 `pets` 필드에 저장합니다. 예전 문자열 배열도 자동으로 읽고, 다른 기존 비서 설정은 유지합니다. 이동 위치는 5초마다, 설정 변경·드래그 종료·정상 종료 시 저장합니다. 강제 종료 때는 최근 5초의 이동이 유실될 수 있습니다. 모든 친구를 돌려보낸 빈 목록도 복원합니다.

## 행동과 상호작용

Idle(대기), Walk(걷기), Run(달리기), Sleep(휴식), Play(놀이), Interact(상호작용)를 지원합니다. 행동 확률·지속 시간·사교성·따라가기 성향은 `desktop/src/pet-profiles.js`와 로컬 캐릭터 manifest의 데이터로 관리합니다. 소심함·사교적·활발함·장난꾸러기·차분함 프로필이 있습니다. 현재 장면의 리소스가 없으면 기본 이미지를 사용하며, 걷기·달리기는 가벼운 상하 움직임으로 보완합니다. 기존 리소스를 새로 그린 걷기 프레임이라고 표시하지 않습니다.

가까운 두 친구는 확률에 따라 바라보기·인사·함께 서 있기·따라가기·함께 놀기·나란히 쉬기를 선택합니다. 두 친구의 상호작용 상태와 종료 시각을 동기화하고, 최대 4초 후 자율 행동으로 돌아갑니다. 종료 후 10초의 재참여 제한이 있으며, 삭제·드래그·상호작용 끄기·일시정지는 진행 중인 짝을 해제합니다. 전용 애니메이션이 없는 인사·휴식은 방향과 작은 기호로 표현합니다. 전용 프레임이 있으면 Interact 애니메이션을 사용할 수 있습니다.

## 로컬 이미지·애니메이션 추가

설정의 **로컬 캐릭터 추가·교체**에서 `pet.json`을 선택합니다. [pet-example](pet-example/README.md)에 manifest 예제가 있습니다. idle(필수)·walk·run·sleep·play·interact 상태에 PNG/GIF/WebM 파일을 지정합니다. 원본 사용자 캐릭터 호환을 위해 JPG/WebP/MP4도 읽을 수 있습니다. 파일 하나는 최대 64MB이며, manifest 폴더 안의 상대 경로만 받습니다. 파일은 앱 저장 폴더로 복사됩니다. 동일 id로 가져오면 기존 항목의 리소스를 교체하고, 새로운 id면 목록에 추가합니다.

저작권이 불분명한 이미지를 다운로드하지 않습니다. 원본 LICENSE의 코드 라이선스와 캐릭터 아트 사용 조건을 그대로 유지하며, 배포 ZIP에도 고지문을 포함합니다. 예제에는 새 캐릭터 그림을 포함하지 않습니다. 사용자 파일의 사용 권한은 사용자가 확인해야 합니다.

## 네트워크 모드

- **오프라인 펫:** 비서 데몬, SSE 연결, 외부 서비스·CLI 탐색, AI 요청, 업데이트 확인을 시작하지 않습니다. 렌더러·Electron net.fetch는 로컬 리소스만 허용하고 Node fetch는 차단합니다. 맞춤법 사전 다운로드도 끕니다. 외부 웹 탐색과 새 창을 차단합니다.
- **사내망 AI:** 위 제한을 유지하면서 별도 간단한 대화 창에서 지정한 내부 모델에만 요청합니다. `http://127.0.0.1:11434/v1`처럼 Chat Completions 호환 API 기본 주소, 설치된 모델 이름, 선택적 API 키를 지정합니다. localhost 또는 사설 IPv4/ULA IPv6 리터럴만 허용합니다. 공인 IP·일반 DNS 이름·리다이렉트·외부 모델 자동 전환은 허용하지 않습니다. DNS·프록시 탐색 없이 해당 IP로 직접 연결합니다. HTTPS는 기본 인증서 검증을 유지합니다. 사설 인증서는 조직의 신뢰 설정에 맞춰 설치해야 합니다. HTTP는 암호화되지 않습니다.
- **일반 모드:** 기존 AI 비서·연동·업데이트 설정을 그대로 사용합니다. 모드 저장 후 재시작이 필요합니다.

API 키는 Electron safeStorage를 통해 OS 암호화 저장소로 보호하고 렌더러에 다시 보내지 않습니다. 키 없이 동작하는 서버도 지원합니다. 대화는 창 메모리에만 보관하며 닫으면 지워집니다. 내부 모델은 이 배포본에 포함되지 않으며, 펫 기능에는 모델 자체가 필요 없습니다.

`Desktop Pets.cmd`와 개발 실행의 `electron . --offline-pets`는 저장된 모드보다 우선하여 오프라인 모드로 시작합니다. `--pet-default`로 만든 ZIP의 Shisa.exe는 최초 실행 시 오프라인이 기본이며, 이후 명시적으로 저장한 모드를 사용합니다. 기존 일반 배포본의 기본 실행 방식은 바꾸지 않습니다. 폐쇄망 운영에서는 Desktop Pets.cmd를 사용하세요. OS·보안 소프트웨어·인증서 검증기의 자체 통신까지 앱이 통제하는 것은 아니며 조직 정책은 별도로 적용합니다.

## 구조와 성능

원본 구조는 `main.js`(창·트레이·IPC·데몬), `preload.cjs`(격리 브리지), `renderer/`(비서 UI), `src/character.js`(리소스), `agent/`(비서 데몬), `windows/dist-win.mjs`(Windows 패키징)입니다. 새로운 기능은 이 구조를 확장합니다.

| 모듈 | 역할 |
|---|---|
| pet-motion / pet-behavior / pet-profiles | 기존 이동 함수, FSM·상호작용, 성격 데이터 |
| pet-store / pet-catalog | v1 설정 호환·배치 저장 형식, 로컬 리소스 가져오기 |
| pet-windows / pet-settings-window | 개별 투명 창·드래그·트레이, 간단한 설정 팝업 |
| network-mode / pet-security | 모드 검증, 요청 경로별 네트워크 제한 |
| network-window / intranet-chat | 암호화 키 저장·모드 선택, 사내망 전용 대화 |

하나의 타이머로 모든 친구를 갱신하고, 이동 중 30Hz·대기 중 최대 10Hz로 계산합니다. 창 좌표가 바뀔 때만 이동시키고, 행동·방향·표시 리소스가 바뀔 때만 IPC로 전달합니다. 동일 세션의 캐시 가능한 로컬 리소스 주소를 재사용하며, 비활성 영상은 정지하고 src를 해제합니다. 제거한 창과 종료한 타이머·IPC 리스너를 정리합니다. 각 펫이 별도 Electron 창이므로 24마리에서의 실제 CPU·메모리 수치는 Windows에서 측정해야 합니다.

모든 좌표는 Electron DIP를 사용합니다. 설정에서 모니터를 선택하거나 드래그로 다른 모니터로 옮길 수 있고, 디스플레이 제거·작업 영역·해상도 변경은 다음 갱신 때 보정합니다. 서로 떨어진 모니터 사이로 자동 순간이동하지 않습니다. Explorer WorkerW에 붙이는 바탕화면 전용 모드는 미구현입니다. 항상 위 끄기는 일반 창의 Z 순서를 사용하며 Explorer 부착과 다릅니다.

## 테스트와 Windows 배포

```sh
npm test --prefix desktop
node desktop/scripts/pet-smoke.mjs
# Windows 빌드 환경에서:
node windows/dist-win.mjs --arch=x64 --no-installer --pet-default
```

GitHub Actions의 **Windows Desktop Pets**는 Windows 러너에서 전체 데스크톱 회귀·신규 테스트 → 기존 배포 스크립트로 Portable ZIP 생성 → 패키징된 실행 파일 스모크 테스트 → Artifacts 업로드 순서로 진행합니다. 해당 Actions 실행의 `Shisa-Desktop-Pets-Windows-x64` 아티팩트를 받아 안쪽 Shisa ZIP을 사용합니다. SHA256SUMS도 함께 제공합니다. 실행 결과를 확인하기 전에는 빌드 성공을 보장하지 않습니다.

구분해서 확인할 항목:

1. 순수 로직·IPC 테스트: FSM 전환, 경계, 크기별 배치, 상호작용 종료·쿨다운, 겹침 완화, 드래그, 중복 소환·상한, 저장 복원, 미디어 검증, 오프라인 요청 차단, 내부 모의 모델 서버.
2. Windows 빌드: 런타임·원본 리소스·비서 데몬·고지문 포함 여부, ZIP·체크섬 생성.
3. Electron 스모크: 실제 5개 펫 창의 로컬 이미지 로딩, 7마리로 추가 소환, 설정 IPC·디스크 저장, 렌더러 네트워크 차단.
4. **수동 Windows 11 GUI 검증(별도):** 투명 합성·클릭 통과·우클릭·실제 마우스 드래그, 다중 모니터 배율 전환, Explorer·전체화면 Z 순서, 네트워크 차단 PC의 장시간 실행, CPU·메모리. CI 빌드나 스모크 성공은 이 항목의 검증을 대신하지 않습니다.
